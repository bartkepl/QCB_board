# QCB (Quad Card Backplane)
Quad Card Backplane for 3U eurocards. Splits UART and 10/100M Ethernet to 4 eurocards.

![Quad Card Backplane board](media/SCA_board_angle.png)

---
## Status : WIP

- First revision of schematic and PCB is done. 
  
---

## Features:
- 10/100 Ethernet connector 
- 4x 3U 6TE eurocard IEEE 1101.1-1998 format (128x30,1 mm)
